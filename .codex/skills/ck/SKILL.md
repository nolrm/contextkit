Read `.contextkit/commands/core/ck.md` and execute the ck workflow.

With no argument, report what is set up and what needs attention. `setup` analyzes the codebase and writes the standards, the always-loaded index, and path-scoped context rules. `update` finishes a `ck update` (asks before moving custom content). `tidy` shrinks always-loaded context and wires guides nothing loads.
